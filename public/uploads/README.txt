Drop your WordPress upload folders here, keeping the exact structure:

  public/uploads/2025/08/...
  public/uploads/2025/09/...
  public/uploads/2025/11/...
  public/uploads/2026/03/...
  public/uploads/2026/04/...

(2026/11 is already included.) Product and category images are matched by the path stored in the
WordPress database, e.g. 2026/04/FLYERS-01-scaled.png. Missing files show a text fallback instead of a broken image.
See docs/MISSING_IMAGES.txt for the exact list of files the catalogue expects.
